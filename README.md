# Attendease
Attendease 🎓📊  Attendease is a modern, offline-first school attendance management system built entirely with HTML, CSS (Tailwind), and JavaScript — no backend required. It leverages LocalStorage to manage schools, admins, teachers, students, attendance records, and notifications, making it ideal for low-resource or rural environments.
